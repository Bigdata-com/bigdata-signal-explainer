Method

How an explanation is built

Every number is computed deterministically from Bigdata.com data before the language model sees anything. {{ model }} only turns those facts and the cited passages into prose. A run makes about 22 Bigdata.com calls and one OpenAI call, and takes 20–40 seconds.

Bigdata.com callcomputed locally, no LLMOpenAI calloptional

Each step, with the calls it makes

Real request bodies for NVDA, as of 2026-10-27, 30-day window. Responses are trimmed to the fields the app uses. All Bigdata.com calls go to https://api.bigdata.com with an x-api-key header. Calls for windows that end before today are cached in SQLite, so re-running a past date makes no new calls.

Deterministic step · plain calculation, no AI

How the numbers are computed

Before any AI is involved, the app works out three answers with simple arithmetic. The same inputs always give the same answers.

A Is the move unusual?

Compare this move with the stock's own moves over the past year. A big move for this stock gets flagged.

B What drove it?

Group the news by event type (lawsuit, partnership, product launch…) and see which groups got more positive or more negative than before.

C Stock or sector?

Check whether similar companies moved the same way. If they did, it's sector-wide; if not, it's specific to this stock.

Running it on your side? You have full flexibility. These are simple rules, not a black box, so you can calculate each step your own way: use your own score, your own factor groups, your own peers, windows and thresholds. Bigdata.com supplies the data and evidence; the logic is yours.
